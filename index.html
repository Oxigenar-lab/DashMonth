    Use este espaço para complementar com contexto que só você tem. O texto some ao recarregar a página — copie antes de fechar, ou use "Baixar PDF" com ele já preenchido.

    Metodologia Cada arquivo enviado é processado com a mesma lógica do painel mensal: linha vermelha = cancelada, coluna W preenchida = venda, coluna AO = motivo do recolhimento (menções a "Oxigenar"/"conosco"/"com a gente" contam como venda para a empresa; "concorrente"/"Pulmonair"/"internet" contam como venda perdida). "Geram receita" conta as solicitações realizadas cujo tipo é Higienização, Locação, Plano de Acompanhamento, Renovação, Venda (produto/serviço/encomenda), WM Locação/Venda ou Orçamento de Manutenção — o mesmo critério usado nos fechamentos mensais em apresentação. O mês de cada arquivo é identificado automaticamente pela data mais frequente dentro dele, não pelo nome do arquivo.
