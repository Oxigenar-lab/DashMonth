    Use este espaço para complementar com contexto que só você tem (ex: campanhas, eventos, mudanças de equipe). O texto some ao recarregar a página — copie antes de fechar, ou use "Baixar PDF" com ele já preenchido.

    Metodologia Uma solicitação é considerada cancelada quando a linha inteira está pintada de vermelho na planilha original (o motivo vem da coluna "PENDÊNCIAS"). As solicitações canceladas ficam fora de todos os números de "Visão geral", "Vendas" e "Recolhimentos" — elas só entram na contagem da aba "Cancelamentos", pra não misturar solicitação que de fato aconteceu com solicitação que foi cancelada. O número de vendas conta apenas as linhas com a coluna "Produtos(s) vendido(s)..." preenchida, para evitar contagem duplicada com outras colunas de venda da planilha. Os recolhimentos usam o motivo do campo "Motivo:", agrupado automaticamente por palavras-chave (ex.: menções a "Oxigenar"/"conosco"/"com a gente" contam como venda para a própria empresa; "concorrente"/"Pulmonair"/"internet" contam como venda perdida). As linhas pintadas de amarelo durante o mês não são analisadas aqui — ficam reservadas para a futura integração com o Google Looker Studio.

    Sobre exportar para PowerPoint: este painel roda inteiramente no seu navegador, então gerar um .pptx nativo aqui não é confiável. Use "Baixar PDF" para um retrato rápido, ou envie este mesmo arquivo no chat com a Claude para gerar uma apresentação em PowerPoint.
